Room screens

Readable from across the hall. Useful up close.

Live status

Available, starting soon or busy, in large type and your brand colours — visible from the end of the corridor.

Timeline or list

Today's meetings sized by duration, with a moving "now" line and free slots you can tap to book.

Book on the spot

15, 30 or 60 minutes in one tap. Edit or cancel bookings made from the screen, end or extend a meeting.

Any size, any orientation

Landscape or portrait, text scaled to the resolution and viewing distance, dark or light theme.

Night mode

Dims outside working hours, shifts pixels against OLED burn-in and wakes up on touch.

Announcements & issues

Push banners to some or all screens, and let people report a broken screen or a cold room.

Any screen

On the wall, on a tablet, in your pocket.

The screen adapts to any size and orientation, in a dark or light theme with your logo and colours. A QR code opens the room on any phone.

  • QR code for phonesPeople scan the screen to see the agenda and book from their phone, through a short-lived signed link.
  • Pair with a codeOpen /kiosk on a tablet, type the 6-digit code in the admin panel — done. Several screens per room.
  • Kiosk-proofKeeps the screen awake, full screen, no zoom, and recovers by itself after a network or server outage.

Get started

Up and running in a few minutes.

  1. 1Run the Docker imageOne image for the web server, the queue worker and the scheduler. SQLite by default, MySQL and PostgreSQL supported.
  2. 2Connect Microsoft 365Register an app in Microsoft Entra ID, grant Calendars.ReadWrite, and paste the IDs in the admin panel. The app checks the permissions for you.
  3. 3Import rooms and pair screensImport the tenant's rooms, then open /kiosk on each tablet and enter its code.
# 1. Generate an application key
docker run --rm ghcr.io/pokertour/o365kioskresources \
  php artisan key:generate --show

# 2. Run the application (SQLite in a volume)
docker run -d --name rooms -p 8080:8080 \
  -e APP_KEY="base64:…" \
  -e APP_URL="http://localhost:8080" \
  -e RUN_MIGRATIONS=true \
  -v rooms-storage:/app/storage \
  ghcr.io/pokertour/o365kioskresources:latest

# 3. Create the first administrator
docker exec -it -e ADMIN_EMAIL=you@company.com \
  -e ADMIN_PASSWORD='a-strong-password' \
  rooms php artisan db:seed --force
